# junk — 지도 만들고, 경로 찍고, 경로대로 주행 (2026-11-05 저녁)

모두 NUC 에서. 이름 하나(예: `final1`)로 `~/ws/junk/routes/final1/` 에 다 모인다.

## ① rosbag → 지도
새 콘이 놓인 코스를 리모컨으로 한 바퀴 돌며 녹화한 뒤:
```
~/go2_record/go2_record_auto.sh final1          # 녹화(평소처럼)
~/ws/junk/tools/make_map.sh ~/bags/<녹화 폴더> final1
```
- FAST-LIO 로 bag 을 다시 돌려 3D 지도(2 cm) → 2D 지도. 시간 ≈ bag 길이 + 1분
- 로봇이 연결돼 있으면 멈추고 묻는다 → 관리자(junk_ctl)를 끈 상태면 `ROBOT_OK=1 ~/ws/junk/tools/make_map.sh ...`
- 2D 지도의 벽 = 세로로 25 cm 넘게 선 면(벽·큰 콘). 경사로·계단 윗면은 바닥으로 남는다

## ② 지도 위에 경로 찍기
```
~/venv/go2/bin/python3 ~/ws/junk/tools/route_editor.py final1
```
- `1` start(출발) · `2` line(지나가는 점) · `4` stopline · `7` parking · `8` exit — 이 다섯만 쓰면 된다
- 빈 곳 클릭 = 고른 점 다음에 새 점 · 점 끌기 = 옮기기 · `d`/오른쪽 클릭 = 지우기 · `n`/`b` 다음/앞 점 · `u` 되돌리기
- **각도**: 점을 고르고 `a` → 바라볼 쪽 클릭(분홍 화살표) · `←`/`→` 5° 씩 · `z` 지움
  - 각도 있는 점 = **거기서 멈춰 그 방향으로 제자리 회전** → 그 점 동작(정지선 대기·주차) 또는 다음 점
  - 각도 없는 점 = 멈추지 않고 지나감. 정지선은 신호등 쪽을 보게 각도를 찍어 둘 것(카메라가 앞만 봄)
  - 출발 정렬로 생긴 회전만큼 자동으로 고쳐서 돈다
- 처음부터 직접 찍기: `route_editor.py final1 --new` (출발 점만 두고 시작, 저장하면 예전 route.json 은 `.bak_시각` 으로 남음)
- `s`(또는 저장 버튼)로 `routes/final1/route.json` 저장
- 확인: `~/venv/go2/bin/python3 ~/ws/junk/tools/show_route.py final1` → `route.png`(벽·콘 0.25 m 안 = 빨강)

## ③ 경로대로 주행
```
~/ws/junk/tools/junk_ctl.sh
```
`Q` → `a`(라이다·브리지·FAST-LIO·카메라·**위치 확인 juninsu**) → 출발 자리에 놓기 → (옮겼으면 `3`) → 리모컨 기립 → `m` → `r`
- `r`: 출발 정렬(처음 3초 스캔을 ① 지도에 맞춤, 약 5초 가만히) → 경로 점들을 이어 따라감(0.25 m/s, ClassicWalk)
- 정지선·주차·출구에서만 6 cm 안으로 선다. 앞 15 cm 안에 무언가 있으면 앞으로 안 감(3초 넘으면 그냥 감)
- 경로 점은 **순서대로만** 지난다(점마다 25 cm 안). ★ 11-06: **막혀서 5초 넘게 제자리**(이동 5 cm·회전 5° 미만)면 그 점을 건너뛰고 다음 점으로. 정지선·주차·출구 0.5 m 안에서 막히면 도착으로 봄
- ★ 11-06 **몸 방향 = 경로 방향**(기본): 걸으면서 몸을 경로 방향으로 돌려 S자로 감(슬라럼 랜덤 시뮬: 몸 닿음 −19 %). 예전 방식 `s` → `H`
- ★ 11-06 **위치 확인(juninsu, 7번 부품)**: 출발·정지선·주차 후 멈췄을 때만 AMCL 로 찾고 3D ICP 로 확인해 맞으면 좌표를 고침. 로봇을 세우지 않음. 끄기 `s` → `J`. 기록 `logs/stop_loc.log`, 설명 `juninsu/README.md`
