## 3. 실행 (요약)
```bash
tools/make_map.sh ~/bags/<녹화 폴더> <이름>              # 녹화 → 지도(routes/<이름>/)
~/venv/go2/bin/python3 tools/route_editor.py <이름>       # 경로 찍기 → route.json
tools/junk_ctl.sh                                         # Q → a → 출발 자리 → 리모컨 기립 → m → r
```
- **관리자 기본 경로**는 `routes/` 안에서 가장 최근에 고친 `route.json` 이다. 시험용 폴더를 `routes/` 에 만들면 그게 기본이 되니 주의할 것.
