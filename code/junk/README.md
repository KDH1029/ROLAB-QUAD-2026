# junk

기록 경로 반복 방식 초기판 (11-05 규정 변경 직후). `src/`, `tools/`, `config/`는 검증본 `nail-1105` 상태.
사용 방법과 구조는 [`juninsu`](../juninsu)와 같다.

## juninsu와 차이

| 항목 | junk | juninsu |
|---|---|---|
| 정지선 | 2.5 s 정지, 빨강 최대 40 s, 미검출 15 s | 2 s 정지, 빨강 지속 시 대기 |
| 주차 대기 | 5.5 s | 6.0 s |
| 추종 속도 | 0.25 m/s, 최소 0.12 m/s | 0.30 m/s, 최소 0.18 m/s |
| 몸 방향 | 이동 방향과 독립 | 경로 접선 |
| 정체 처리 | 경유점 후퇴 4회 후 건너뜀 | 5 s 정체 시 건너뜀 |
| 전방 정지 | 모든 점 | 지도 벽 제외 |
| 주차 후 걸음새 | - | ClassicWalk 재전송 |
| 회전 실패 대응 | - | 전진하며 회전 |
| 정지 시 위치 확인 | 미연결 | 관리자에 연결 |
| 기본 경로 | 가장 최근 수정된 `routes/*/route.json` | `routes/rec1118x` |
