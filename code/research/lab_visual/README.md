# 정밀 항법 시험장 (노트북 전용)

라이다+IMU 오도메트리 위에 **시각 정보(YOLO + 깊이)**를 더해 위치추정을 보정하고,
대회 규정(횡단보도 발 배치, 초록불 30초, 보행자 회피)을 만족하는지 녹화본으로 시험한다.

## 왜 별도 작업공간인가
`~/ws/lab` 은 팀원 스택 재생 검증용이다. 여기는 **새로 만드는 기능**을 시험하는 곳이라
그쪽을 건드리지 않는다. 젯슨에도 접속하지 않는다. 검증이 끝난 것만 나중에 배포한다.

## 규정에서 나온 요구사항
| 규정 | 필요한 것 |
|---|---|
| 횡단보도 위에 발 **최소 1개** | 네 발의 지도 좌표, 횡단보도 영역 |
| 정지구역에 발 **3개** | 같은 것 + 정지구역 영역, 정지 자세 역산 |
| 초록불 **30초** 동안만 진입 | 신호 판정 + 시간 필터 + 카운트다운 |
| 보행자(마네킹) 회피 | 라이다 + YOLO pedestrian |

## 구성
- `tools/` 로봇 없이 녹화본으로 도는 계산·검증 도구
- `config/` 구역 정의(횡단보도·정지구역), 랜드마크 좌표
- `out/` 결과 CSV·그림
- `src/` ROS 노드 (검증이 끝난 것만)
