# 지도 품질 / 외부파라미터 교정 자료  (2026-09-28~29)

## 무엇을 재려고 만든 것인가
FAST-LIO 지도의 벽 평면 두께로 정합오차를 재고, 그 원인을 하나씩 소거했다.

## 파일
| 파일 | 내용 | 재생성 비용 |
|---|---|---|
| `ba_accum.npz` | (패치,프레임) 394,788쌍의 6차원 모멘트. 점 78.3M 압축 | 재생 15분 + 누적 2분 |
| `cal_mat_out.txt` | `extrinsic_est_en: true` 재생의 FAST-LIO 자가추정 로그 (26열) | 재생 15분 |
| `floormap.npz` | 바닥 5cm 격자 (점수, 평균높이) | 재생 자료 필요 |

`ba_accum.npz` 만 있으면 재생 없이 다음을 다시 계산할 수 있다:
평면 두께, 전분산 분해(프레임내/프레임간), 6자유도 교정, 번들조정 상한.

## 결론 (도구는 ~/ws/hesai_tools/)
```
진짜 평면인 벽에서  21.0 mm = 센서 9.1 + 정합 19.0     <- clean.py, within.py
외부파라미터 6자유도 최적해도 -2.5%                      <- cal6.py
번들조정 상한: 자유도 1536개로도 포화, 평면이 8장뿐      <- ba_solve.py
XT16 바닥 링 간격 0.15m ≈ 구멍 크기 -> 구멍 탐지 불가    <- rings.py
구멍은 /lowstate 로 감지 (계단과 구별됨)                 <- foothole.py, classify.py
```

## 주의
- 지도 품질을 잴 땐 **프레임내 두께 < 12mm 인 패치만** 쓸 것.
  안 거르면 평면 아닌 면(최대 78mm)이 섞여 37mm 로 부풀려진다.
- `mat_out.txt` 는 FAST-LIO 노드가 뜰 때마다 덮어쓴다(소스 913행). 즉시 복사할 것.
