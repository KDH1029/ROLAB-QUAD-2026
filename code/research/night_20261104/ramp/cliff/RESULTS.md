## 의심 / 확인 필요

1. **L1 점 높이**: 경사로 오를 때 L1 이 표면보다 0.2~0.3 m 높게 찍는 사례(84 s). L1 frame_id = base_link. l1_frame_check.py(몸체 회전 vs 요만 회전)로는 결론 못 냄.
   거부권·낭떠러지 둘 다 L1 에 기대므로, L1 시각·좌표계 점검이 다음 1순위.
2. 단 위 지도 점: 단 중심 0.5 m 안 점 z 분위 5/50/95% = −0.05/0.05/0.23 (발 ≈ −0.02). 단 표면 위 0.2~0.3 m 에 넓게 점이 있다. 정체 미확인(턱·난간·사람·잔상?).
   단 위에서 잡힌 낭떠러지 가장자리 칸 높이도 발 + 0.32 m 근처 — band 가 진짜 가장자리를 깎는 이유.
3. ego_planner 가 레이캐스팅으로 빈 공간을 지운다면 합성 점(실제 반사 없음)이 지워질 수 있다. 오프라인 지표는 '/cloud_planner 에 ego 규칙'만 본다 — 재생 때 플래너 지도에서 단 가장자리가 막히는지 한 번 눈으로 확인.
4. 오프라인 평가는 지도 궤적(GT)으로 점을 놓았다. C++ 재생은 재생 FAST-LIO 자세라 수치가 조금 다를 수 있다(tv2: 파이썬 0.63% vs C++ 0.94% 수준 차).
