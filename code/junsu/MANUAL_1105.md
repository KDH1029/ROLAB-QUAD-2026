## 3. 예선 출발

1. 로봇을 **출발 자리·방향**에 놓는다(경로 지도의 start 와 같게). 출발 정렬이 ±0.3 m·±10° 까지 맞춰 준다.
2. `a` 를 누른 뒤에 로봇을 옮겼으면 **`3`**(FAST-LIO 다시 켜기 — 지금 자리가 원점).
3. 리모컨으로 **기립**.
4. **`m`** — 모터 켜기(이제 로봇이 움직일 수 있음).
5. **`r`** — 출발. 먼저 **출발 정렬 약 5초**(가만히 둘 것) → 상태 메시지에 "출발 정렬 OK" → 경로 시작.
   - ★ 기립하고 **30초 안에** `r` (뒷다리 과열)
   - "거부(원래 경로)" 가 나오면 출발 자리가 많이 틀린 것 → 그대로 가도 되지만 경로가 그만큼 밀림

러너가 하는 일(경로 파일 `maps/route_map.json` 순서대로):
- **정지선**: 접근 → 2.5초 정지 → 초록 1초 연속이면 출발. **빨강이 보이는 동안은 최대 40초 기다림**, 아무것도 안 보이면 15초 뒤 출발.
  대기 중 0.6초 넘게 계속 움직여야 '움직임'(경사 위 잠깐 미끄럼으로 다시 접근하지 않음)
- **콘 구간**: 카메라(+라이다) 콘을 피해 감
- **주차**: 도착·멈춤(**회전 안 함**) → **엎드리기(네 다리 바닥, StandDown)** → 5.5초 → 일어나기(StandUp → BalanceStand)
  → **넓은 범위 재정렬(±0.5 m, ±20° — 자세 바꾸면 FAST-LIO 가 틀어짐)** → 다음 점 쪽으로 회전 → 다음 점
- **출구**: 몸 전체가 Out Line 밖으로 나가면 정지(모자라면 천천히 밀고 나감)
- 벽·콘에 붙어 4초(**콘 구간은 2초**) 못 움직이면 조금 물러났다 다시 감
- 제자리 회전: 최소 0.35 rad/s, 7° 안이면 완료, 6초 한도(전엔 마지막 10° 를 못 돌아 매번 10초 버림)
- **콘 피하기 단계(벽은 절대 안 바꿈)**: 벽이 25 cm 안으로 붙으면 콘을 덜 피하고(콘 여유 0.28→0.20, 세기 150→50),
  4초 막히면 **콘 무시**(벽은 그대로 피함). 0.6 m 빠져나오면 한 단계, 벽에서 35 cm 넘게 2초면 처음으로 되돌림
- **핀(pin)**: 경로 편집기에서 `9` 로 콘 앞뒤에 핀을 찍으면, 연속된 핀과 앞 점을 **회귀 곡선(스무딩 스플라인, 핀에서 3 cm 안)** 으로 이어
  ego 없이 그 곡선을 내다보기 추종(0.25 m/s, 중간 핀에서 안 멈춤).
- **벽 추종(wall)**: 경로 편집기 `0` 으로 찍은 점까지는 merge `go2_wall_patrol` 방식 — `/scan` 에서 옆벽·앞벽을 2D RANSAC 직선으로 잡아
  **옆벽 거리를 유지하고 벽과 나란히**(지도·FAST-LIO 안 씀, 콘 점은 이상치로 버림). 어느 쪽 벽·목표 거리·앞벽 멈춤 거리는 지도에서 구간 모양으로 자동.
  앞벽이 그 거리까지 오거나 구간 길이만큼 가면 다음 점. 벽을 못 잡으면 그 점 쪽으로(벽은 피함). 주차 칸처럼 벽을 따라 들어가는 곳에 쓴다
  콘은 안 보고(핀으로 피해 감) 벽은 봄. 주차 칸 앞 콘처럼 ego 가 한 번에 가다 콘을 치는 곳에 쓴다
- **경로 따라가기**: 콘 무시 뒤에도 **10초(콘 구간 5초)** 동안 목표에 30 cm 도 못 가까워지면 ego 를 세우고 러너가 경로점으로 직접 간다
  (0.25 m/s, 콘 무시). 벽은 계속 본다 — 28 cm 안 벽에서 비켜나고, 앞 22 cm 안이 벽이면 앞으로 안 감. 목표 40 cm 안(또는 25초)이면 보통 주행으로
- **걸음새**: 전 구간 **ClassicWalk** 하나(구간마다 바꾸면 odom 이 출렁임). 출발할 때·주차에서 일어난 뒤 한 번 보냄

## 4. 경기 중 키

| 키 | 하는 일 |
|---|---|
| **`x` / 스페이스** | **비상 정지** — 모터 끔 + StopMove + 러너 끔. 가던 목표 번호를 기억 |
| `p` | 정비 멈춤(러너 끔 + 모터 끔, 번호 기억) |
| `M` | 모터만 끔 |
| `m` | 모터 켬 |
| `r` | 처음부터(출발 정렬 포함) |
| **`R`** | **이어가기** — 엔터 = 기억한 번호, 숫자 = 그 목표부터 |
| `1`~`9`, `0` | 그 부품 다시 켜기 (0 = 위치 감시) |
| `s` | 작전 바꾸기(아래) |
| `l` | 부품 로그 보기 |
| `q` | 관리자만 끔(부품은 계속 돎) · `Q` 전부 끔 |

### 비상 정지 뒤 이어가기
1. 상태판 **"위치(FAST-LIO)"** 가 실제 자리와 맞는지 본다.
2. **`m` → `R` → 엔터** — 가던 목표부터 이어 간다(처음 정렬한 경로 그대로).
- ★ **`3`(FAST-LIO 다시 켜기)을 누르면 위치를 잃는다** → 출발점에 다시 놓고 `r` 로 처음부터.
- 손으로 들어 옮겼으면 위치 줄이 틀어졌을 수 있다 → 다르면 출발점에서 다시.

### 위치 감시
FAST-LIO 위치를 지도(AMCL)와 계속 비교한다.
- **OK / WARN**: 그냥 감
- **STOP**(30 cm 또는 8° 넘게 1초 어긋남): 러너가 그 자리에 서고, 그 자리 스캔으로 ICP 를 다시 돌린다
  - ICP 가 맞으면 좌표를 고치고(남은 목표 다시 계산) 계속 감
  - **4초 안에 안 풀려도 그냥 계속 간다**(감시 오판이 경기를 멈추지 않게)
- 이상하면 `s` → `L` 로 위치 감시를 끈다(러너는 감시 없이 그대로 감)

## 8. 아직 실기에서 확인 안 된 것

- review ego(경로 생성)로 실제 주행
- 출발 정렬(기립 상태에서 처음 동작)
- 위치 감시 STOP·ICP 재정렬, 라이다 콘 추적기와 카메라 콘 묶기
- 주차 엎드리기(StandDown)·일어나기(StandUp→BalanceStand) — 엎드린 높이 0.06 m 실측이라 판정(0.15 m 아래)은 맞을 것
- 전 구간 ClassicWalk 로 계단·경사로(X자 꼭대기)

이상하면 바로 끌 수 있다: 경로 생성 `s`→`9`(junsu ego), 위치 감시 `s`→`L`, 출발 정렬 `s`→`0`, 콘 `s`→`7`.

벽 반발(soft)은 팀원 값보다 세게: optimizer.lambda_obs 250(팀원 120), 밀어내기 시작 0.50 m(0.45). 벽 여유(hard 0.20)는 그대로 — 슬라럼이 더 막히지 않게.

## 넘어졌을 때 (v2, 11-05 예선 12:12 사고 반영)
- 몸이 50° 넘게 기울면 러너가 **넘어짐**으로 보고 바로 멈춘다(관리자 러너 줄 FALLEN).
- 로봇을 다시 세우면(자동 복구 또는 리모컨) 2초 뒤 BalanceStand → **넓은 재정렬(±0.6 m, ±45°)** → 가던 목표부터 이어 간다.
  주차 일어나기 중에 넘어졌으면 주차는 한 것으로 보고 다음 점으로.
- 같은 목표에서 물러나기 6번이면 재정렬을 한 번 부탁하고, **12번이면 멈추고 기다린다(STUCK_HOLD)** — 벽에 계속 부딪혀 감점 쌓이는 것 막기. 사람이 보고 `R`.

## 몸 모양 안전 필터 (v2)
- 모든 이동 명령(ego·러너·측정 도구)이 모터로 가기 전에 `footprint_guard_node` 를 거친다(/cmd_vel → /cmd_vel_safe).
- 로봇을 **0.70 × 0.40 m 직사각형(다리 포함, +3 cm)** 으로 보고 1초 앞까지 쓸고 지나갈 자리를 그려, 벽(쌓아 둔 벽 기억 — 뒤쪽 포함)과
  겹치면 속도를 줄이거나 회전·옆걸음을 조금 바꾸고, 없으면 멈춘다. 벽 앞 0.9 m 부터 서서히 줄이고 몸 앞 약 8~12 cm 에서 선다.
- 콘은 안 본다(벽 접촉만 감점 — 콘 무시·경로 따라가기와 안 싸우게).
- 관리자 `a` 와 `m` 이 같이 켠다. 끄기: `s` → `F` (모터 내림 → `m`). 벽 기억이 안 오면 검사 없이 그대로 넘긴다.
- **고착 탈출**: 움직이라는 명령을 1.5초 넘게 막으면 여유를 0 으로(좁은 틈 통과), 3초 넘으면 '벽 쪽으로 더 파고드는 움직임'만 막고 나머지는 통과.
  0 단계 검사를 통과하면 다시 0 단계. 바로 앞이 벽이면 끝까지 막고 러너 물러나기가 처리한다.
- **벽 기억은 20초**: 20초 넘게 다시 못 본 벽 칸은 잊는다(위치가 흐르거나 넘어진 뒤 남는 '유령 벽'으로 막히지 않게). 지나온 뒤쪽 벽은 그동안 기억.
