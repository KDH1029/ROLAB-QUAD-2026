# xentry — 첫 X 통로 입구에서 북쪽 막다른 통로로 빠지는 원인 (11-06, 도메인 78) — 메인 세션이 받아 적음

## 결론
- **원인은 시뮬 벽 파일의 잡음 칸 하나다.**
  - `sim/sim_walls_rec1650.npy` 의 외톨이 칸 (1.98, 0.10)이다. 1650 지도 바닥 위 0.46 m 복셀 1개(cnt 2)다.
  - 몸 접촉 판정(obc)은 이 칸을 빼지만 가상 라이다 벽에는 남아 있었다.
  - 이 칸과 X 통로 왼쪽 벽 끝 (1.70, 0.38) 사이가 0.396 m 라 ego 팽창 0.20 m×2 보다 좁다 → ego 격자에서 입구가 막힘.
  - 격자 원점·잡음을 넣어 300번 돌리면 입구가 열려 보이는 건 20~23% 뿐이다(판마다 엇갈린 이유). 칸을 빼면 100% 열린다.
- **입구가 막히면 A* 는 입구에서 안 보이는 세로 벽 윗부분(x≈1.55, y 1.3~1.9)을 빈 곳으로 보고 북쪽 통로를 고른다** → 들어가서야 막다른 곳임을 안다.
- **main(16:54)도 3/3 똑같이 빠졌다.**
  - main 은 ROUTE_FOLLOW(콘 2단계 뒤 10초)가 33~39초에 끌어냈다.
  - **v2 는 새 경로 이탈 되짚기(1.0 m)가 먼저 걸려 ROUTE_FOLLOW 가 한 번도 안 걸렸다**(되짚기 4~64번).
- ego 인자(lambda_obs·safe_dist·rotate·wall_memory)·미리 넘어가기·SNAP 은 원인이 아니다.
- **실기에는 이 원인이 없다**(실시간 라이다엔 이 칸이 없음 — 16:54 실기 통과와 맞음).
