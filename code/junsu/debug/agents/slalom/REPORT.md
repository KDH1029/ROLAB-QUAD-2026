# slalom 에이전트 보고 — 슬라럼 구간(rabain→rabaout) 점검 (11-06, 도메인 80) — 메인 세션이 받아 적음

## 결론
- **원본 v2 로는 시뮬 12판 모두 슬라럼을 제대로 통과하지 못했다.**
  - 11판의 '완주'는 ego 가 코스를 거꾸로(line2→정지선→line6→line3) 돌아 rabaout 에 닿은 우회였다(슬라럼 길 덮음 0.2~0.45). 1판은 STUCK_HOLD.
- 원인:
  - ① 대체 길 추종(drive_toward)이 옆 콘까지 '앞 막힘'으로 봐서 밀어내기 0.08 m/s(문턱 아래)만 남아 제자리 → 6초 포기
  - ② 콘 구간엔 경로 이탈 감시가 없어 우회를 못 막음
  - ③ 대체 길 시작에 거리 제한이 없음(2 m 밖에서 벽 쪽 직진)
  - ④ 가까운 꼭짓점+1 부터 시작해 모서리를 건너뜀
  - ⑤ 콘 구간 carrot 이 뒤로 감
  - ⑥ 되짚기 옆걸음이 문턱 아래
  - ⑦ 시뮬 리포트의 슬라럼 구역이 엉뚱함(R[6:25])
- **패치(slalom_fix.patch) + `SLALOM_MODE=path` 가 최선.** 10판 모두 완주, 우회 0, 길 덮음 1.0이었다.
  - path 5판 기준: 슬라럼 20.6~21.6초, δ10 접촉 0초, δ0 3.5~4.7초(사람이 몬 길이 콘에 7 cm까지 붙는 꼭짓점 6).
  - auto 는 콘 검출이 있으면 ego 를 먼저 시도하다 접촉이 늘었다(22.8~56초, δ10 0.4~5.4초).
- 회전은 정상이다: 넘어서 완료되며 rabain 3.0~3.6초, rabaout 2.6~2.8초.
  - 몸 모양 필터를 켜면 접촉 0 이지만 회전 시간초과 2번·대체 길 멈춤 2번으로 49초가 걸렸다.
