## 결론
1. **"시뮬 시간은 실제의 2배"는 틀렸다.** 트인 구간 9개는 시뮬과 실제가 +4% 로 맞는다(41.8 → 43.4초).
   - 초과 시간의 99% 는 좁은 곳 5개(정지선1 입구·rabain·rabaout·line3·line6)에서 시뮬만 갇혀서 나왔다(물러남·콘 무시 직진; 실제는 0번).
2. **회전은 시뮬이 낙관적이었다.** 실제 로봇은 제자리 회전을 약 0.30 rad/s 아래에서 안 한다.
   - 문턱 0.30 + 지연 0.15초를 넣으니 16:54 회전 시간초과 4/4번·40.8초가 그대로 재현됐다.
3. **X 입구에서 갇힌 원인은 벽 두께가 아니라 X 가르개 끝 위치가 12 cm 어긋난 것이다.**
   - 같은 line1 점에서 벽까지 거리가 실제(1459) 0.39 m, 시뮬(1650 변환) 0.27 m 다.
   - 가르개 끝 13칸을 지운 세계에서는 7.4초에 통과했다(실제 6.4초).
4. **보정 시뮬 결과:**
   - 16:54 main 완주 199초(+48%). 슬라럼을 뺀 구간은 ±10% 안이다.
   - v2(GUARD=off, hybrid 경로) 2판 완주 200.0 / 195.5초, X 입구 10.8 / 10.6초.
   - v2 회전 시간초과 0번, 회전 합 16초(main 40.8초).
   - 남은 문제는 rabaout 슬라럼 약 80초다(시뮬 콘이 굵어 비관적).
