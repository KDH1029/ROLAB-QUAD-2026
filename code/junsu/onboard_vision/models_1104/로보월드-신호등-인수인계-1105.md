# 로보월드 신호등·라바콘 비전 인수인계 (2026-11-05 아침 기준)

> 이 문서를 그대로 다른 팀원에게 붙여넣으면 이어서 작업할 수 있게 쓴 것.
> "확인 필요"라고 적힌 건 아직 실물로 검증 안 된 가정이다.

## 0. 배경
- 대회: 2026 로보월드 4족보행 로봇경진대회, **자율주행 종목**. 로봇 Unitree Go2.
- 로봇 연산 컴퓨터: **인텔 NUC** (NVIDIA GPU 없음 → TensorRT 못 씀, **OpenVINO** 사용). Jetson 아님.
- 카메라: RealSense D435, 컬러 토픽 `/camera/color/image_raw`. ROS2 Jazzy.
- 규정상 **모든 연산은 로봇에 달린 보드(NUC)에서**. 노트북에서 추론 돌리면 실격 사유.
- 비전 담당 파트: 신호등 인식 + 정지선에서 "2초 정지 → 신호 판단 → 출발 명령".

## 1. 규정 중 비전 관련 핵심
- 정지선+신호등 **2곳, 각 50점**: 정지선 사각형 안에 **앞다리 2개** 넣고 **2초 이상 정지** → 초록이면 출발 / 빨강이면 초록 될 때까지 대기. 신호는 **5초마다** 바뀜. 출발 후 빨강으로 바뀌는 건 OK.
- 완주 200점 조건 = **모든 미션 "시도"** + OUT 라인 통과 → 정지선에서 멈추는 시도 자체를 빼먹으면 안 됨.
- 장애물(라바콘) 회피: 안 닿으면 개당 +10 (최대 10개). 닿으면 0점일 뿐 감점 아님. 벽 접촉은 1초당 -10.
- 주차 50점: 벽의 QR+P 표식, 앉아서 5초.

## 2. 완성된 것

### 2-1. 새 모델 `tl_cone_1104` (YOLOv8n, 입력 640)
- 클래스 4개: `0 tl_red, 1 tl_green, 2 unknown, 3 cone`
- 데이터: 팀 데이터셋 `ds_tl5_cone`(pedestrian·temi 클래스 삭제) + 이번 대회장 사진 `arena1104_tl_cone_1500` 1500장(팀원 모델로 자동 박스 → 손으로 수정) → **train 3402장 / val 461장**
- 학습: 팀원 모델 `tl5_cone_aug500.pt`에서 이어 학습, `hsv_h=0`(색상 증강 끔 — 빨강/초록 뒤바뀜 방지), 100에폭·patience 30 → 35에폭에서 조기종료, 최고 성능 5에폭
- 위치: **Google Drive `MyDrive/runs/tl_cone_1104/weights/`** → `best.pt`, `fp16_openvino_model/`, `int8_openvino_model/`

| (val 461장) | FP16 | INT8 |
|---|---|---|
| tl_red mAP50 / 정밀도 | 0.990 / 0.956 | 0.983 / 0.942 |
| tl_green mAP50 / 재현율 | 0.966 / 0.916 | 0.961 / 0.915 |
| cone mAP50 | 0.988 | 0.985 |
| 추론속도 (Colab 2코어 CPU) | 108ms | 85ms |

- **결정: FP16 사용**, INT8은 NUC에서 너무 느릴 때 쓰는 예비.
- 참고: 이전 팀원 모델 tl_green mAP50 0.921 / 재현율 0.842 → 이번 0.966 / 0.916 (단, val 세트가 달라 완전 동일 비교는 아님)

### 2-2. 정지선 대기 명령 `wait_green.py` (+ `tl_go_gate.py` 같은 폴더 필수)
- 지점(웨이포인트) 이동 사이에 끼우는 **명령 하나**. 실행된 순간부터 정지 시간을 세고, 조건 만족하면 종료(exit 0) → 다음 명령 실행 = 출발.
- 조건: **최소 2.5초 정지**(규정 2초 + 여유) **AND 초록이 0.6초 연속**. 빨강/UNKNOWN 한 프레임이라도 섞이면 초록 연속 카운트 리셋.
- 신호 판정이 1초 이상 안 들어오면(판정 노드 죽음) 출발 안 함.
- 입력: `/traffic_light/state` (std_msgs/String: RED|GREEN|UNKNOWN)
- 옵션: `--min-stop 2.5 --green-confirm 0.6 --max-wait 0`(0=무한대기, 예: 20 주면 20초 후 강제출발)
- 노트북에서 `ros2 topic pub /traffic_light/state std_msgs/String "{data: RED}"` → GREEN 바꿔가며 테스트 통과 (빨강 대기, 판정 끊김 시 대기, 초록 0.6초 후 "출발!").
- 정지선 위치 자체는 **주행팀 지점저장(오돔)**이 담당: 정지선에 로봇 세워 앞다리 2개 넣고 지점 저장(S1, S2).
- `tl_go_gate.py`는 오돔으로 정지선 도착을 스스로 판단하는 노드 버전도 들어 있지만, 지점저장 방식이면 안 써도 됨 (`wait_green.py`가 판단 로직만 가져다 씀).

### 2-3. 도구 모음 `tl_kit/`
| 파일 | 용도 |
|---|---|
| `wait_green.py`, `tl_go_gate.py` | 위 2-2 |
| `prelabel.py` | 모델로 YOLO 박스 자동 초안 (`--model-classes`로 모델 클래스 번호 그대로) |
| `drop_classes.py` | 라벨에서 클래스 삭제 + 번호 당기기 (자동 백업) |
| `merge_into_ds.py` | 새 라벨 폴더를 데이터셋에 합침 (클래스 순서 검사, 연속프레임 묶음 단위 train/val 분할) |

## 3. 다음에 할 일 (순서대로)
1. **모델 NUC로 옮기기**: 드라이브에서 `fp16_openvino_model` (+예비 `int8_openvino_model`) 폴더 다운로드 → NUC로 복사. **폴더 이름은 반드시 `_openvino_model`로 끝나야 함** (아니면 ultralytics가 형식 인식 못 함).
2. **NUC에서 신호등 노드 실행** (`--imgsz 640` 필수, 노드 기본값 1280):
   ```bash
   python3 yolo_tl_node.py --detector custom --weights fp16_openvino_model \
       --imgsz 640 --topic /camera/color/image_raw --confirm-n 1
   ```
   - 확인 필요: NUC의 `yolo_tl_node.py`에 `--detector custom` 옵션이 있는지 (`grep -c "'custom'" yolo_tl_node.py`), 클래스 이름에 red/green 들어간 걸로 판정하는지, `/traffic_light/state`를 RED/GREEN/UNKNOWN 문자열로 내보내는지.
   - `--confirm-n 1`인 이유: 초록 연속 확인은 `wait_green.py`가 대신 함.
3. **속도 확인**: NUC에서 추론 FPS. 너무 느리면 INT8로 교체.
4. **실물 신호등 테스트**: 정지선 위치에 로봇 세우고 빨강↔초록 10번 이상 전환 → 오판(특히 빨강을 초록으로) 없는지. 주변 비상구등(초록 LED)·라바콘이 화면에 들어올 때도 확인.
5. **주행팀 연결**: 정지선 지점 S1·S2 저장(앞다리 2개 사각형 안) → 주행 순서에 끼우기
   ```bash
   <정지선 S1로 이동하는 명령>   # 도착해서 멈춘 '뒤에' 끝나야 함 (확인 필요)
   python3 wait_green.py
   <다음 지점으로 이동하는 명령>
   ```
   파이썬 순서 스크립트면: `subprocess.run(['python3', '<경로>/wait_green.py'], check=True)`
6. **라바콘 인식 결과 사용처 결정**: 새 모델이 cone도 잡지만, 현재 라바콘 박스를 토픽으로 내보내는 노드는 없음. 주행팀이 라바콘 위치를 쓸 거면 내보내는 노드 필요 (미정).

## 4. 주의사항 / 겪은 함정
- NUC/노트북 시스템 파이썬에 `pip install ultralytics` 하지 말 것 → numpy 버전 올라가서 cv_bridge 세그폴트 난 적 있음. 가상환경(`~/yolo_venv`) 사용.
- 새 터미널마다 `source /opt/ros/jazzy/setup.bash`.
- labelImg는 **이전 저장 폴더를 기억**함 → 실행 시 세 번째 인자로 저장 폴더 지정: `labelImg <이미지폴더> <classes.txt> <저장폴더>`.
- 팀원이 준 `frames.csv`의 `tl_count`는 정확하지 않음(신호등 없는 사진에도 1로 적힌 경우 있음).
- Colab: 학습 중 ▶ 다시 누르면 처음부터 재학습됨. 런타임 리셋 후엔 `drive.mount` 다시. 결과는 드라이브에 저장됨.
- 노트북 디스크 여유 적음(정리는 대회 후).
