# 설계 결정

| 항목 | 선택 | 제외 | 근거 |
|---|---|---|---|
| LIO | FAST-LIO | LIO-SAM | LIO-SAM은 9축 IMU 전용, Go2는 6축 |
| 위치 보정 | FAST-LIO + AMCL(Omni) + 출발 정렬 | SLAM 단독, 다리 odom 기반 AMCL | 오차 9~14 cm → 3~3.6 cm |
| 지도 정밀도 | 21 mm에서 중단 | SC-PGO, 번들조정, 외부파라미터 최적화 | 개선 ≤ 2.5% 또는 악화 |
| 바닥 구멍 | L1 + 발 접지 감지, 차선 주행 | XT16 탐지, 개별 구멍 회피 | XT16 링 간격(15 cm) = 구멍 크기 |
| 연산 | NUC + 내부 PC 비전 | 외장 젯슨 | 젯슨에서 FAST-LIO 프레임 43.5% 손실 |
| 고빈도 노드 | C++ | Python | Python 역직렬화만으로 CPU 45~70% |
| 규정 변경 대응 | 기록 경로 반복 | 실시간 콘 인식·회피 | 대형 콘 YOLO 미인식, 콘 위치 고정 |
| 걸음새 | ClassicWalk 단일 | 구간별 전환 | 전환 시 odom 흔들림 |
| 주차 | StandDown → StandUp | Sit / RiseSit | 규정(4다리 접고 착지) |
| 신호등 엔진 | TensorRT FP16 | INT8 | INT8 초록 재현율 71% (원본 84%) |
| 주행 중 ICP 보정 | 정지 시에만 | 연속 보정 | 슬라럼에서 25~31 cm 오답 |
| 감시 노드 | 경고 위주 | 이상 신호마다 정지 | 정지 14회 중 실제 오류 0회 |
| 백업 위치추정 | 미적용 | 자동 전환 | 지도 좌표와 당일 좌표 정렬 미해결 |

## 지도 정밀도 개선 시도

| 방법 | 결과 |
|---|---|
| 외부파라미터 6자유도 최적화 | −2.5% |
| FAST-LIO 외부파라미터 자동 추정 | 공분산 붕괴로 잘못된 값(y 114 mm)에서 멈춤 |
| 라이다-IMU 시각 오프셋 | 0% |
| SC-PGO | +15.6% (악화) |
| 번들조정 | 경기장 평면 8장으로 구속 불가 |
| 다중 스캔 누적 정합 | 일치율 98.6% → 70.9% |

남은 정합 오차 19 mm는 16빔 라이다의 한계로 보고 중단.

## 규정 변경 대응 (11-05)

- 변경 내용: 콘 고정, 대형(높이 0.7~0.8 m) 교체, 기존 YOLO로 인식 불가
- 기존 콘 추적기 설정으로 대형 콘 절반만 검출, 1.0 m 통로에서 실시간 재계획 위험
- 콘이 고정이면 지도 = 코스 → 리모컨 주행으로 경로 기록 후 추종
- 위치추정·하드웨어는 유지, 신호등만 YOLO
- 한계: 경로 이탈(미끄러짐, 걸음 흔들림)이 모델에 없음
