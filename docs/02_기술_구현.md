# 기술 구현

수치는 대부분 녹화 재생 기준.

## Localization

### FAST-LIO

- 입력: XT16 + 몸통 IMU (L1 입력 시 2분 내 발산)
- 다리 속도 결합 포크 `ws_fastlio_tunable`
  - 카이제곱 게이트, 기울기 12° 또는 회전 40°/s 초과 시 결합 중지
  - 자세 점프 상한
- 주요 설정

| 파라미터 | 값 | 이유 |
|---|---|---|
| `det_range` | 30 | 60이면 7 m 방에서 궤적이 25 m 밖으로 흐름 |
| `preprocess.max_range` | 15 | 전시장 먼 점(구조물·관중)으로 인한 출렁임 제거 |
| `extrinsic_est_en` | false | 켜면 정지 중 1.5~2.5 cm 흔들림 |

- 성능: 지도 대비 오차 중앙 1.7 cm / 최대 3.9 cm, 각도 0.8° 이내 (슬라럼 밖 4분)
- 지도 벽 두께 21 mm (센서 9 mm + 정합 19 mm)

### AMCL

- Omni 이동모델: 0.5 m 초과 오차 시간 306 s → 0 s (528 s 녹화)
- 수직성 스캔(`scan_mode: vertical`): 경사로·계단 오인식 제거
- 이동 입력 FAST-LIO: 기준선 대비 오차 9~14 cm → 3~3.6 cm
- 출발 초기화 `code/merge_tmp/scripts/go2_amcl_init.py`: 공분산 포함 `/initialpose` + 정지 중 갱신 요청 (0.49 m 오차 → 10초 후 6 cm)

### 출발 정렬

- 기립 1초 후 3초 스캔을 지도에 정합, 경로 파일을 당일 좌표로 변환
- 일치율 64~68% → 95.5~98.9% (손 배치 오차 13~20 cm)
- ±0.3 m / ±10° 초과 결과는 거부 (직사각형 경기장 오정합 방지)
- `code/merge_tmp/scripts/go2_start_align.py`, `start_align_core.py`

### 정지 시 위치 확인

- 출발·정지선·주차 후 정지 상태에서만 AMCL + 3D ICP로 확인 후 보정
- 주행 중 보정 안 함 (슬라럼에서 ICP가 25~31 cm 오답)
- `code/juninsu/juninsu/stop_loc_node.py`

## Planning (EGO-Planner)

- 격자 0.1 → 0.05 m, 벽 팽창 0.20 m, 콘 팽창 0.28 / 안전거리 0.38 m
- 팽창·반발 분리, 제어점 재추출, 궤적 검증, 충돌 예상 시 정지
- 결과: 계획 성공률 71~75% → 88%, 벽 최소 거리 0 → 0.23 m
- 사전 벽 지도: 지도 좌표 벽을 1초마다 계획기 좌표로 변환

## Robot control

- 걸음새: 전 구간 ClassicWalk. BalanceStand 후 전송, 응답 실패 시 재전송
- 최소 유효 명령: |v| < 0.015 → 0, 그 외 최소 0.10 m/s (회전 0.25 rad/s)
- 직진 쏠림 보정: `wz -= per_vx·vx + bias`, ClassicWalk 기준 0.0156 / +0.0397, 잔여 1°/m 이내
  - `code/merge_tmp/scripts/go2_yaw_drift.py`, `code/junsu/tools/yaw_trim_measure.sh`, `code/juninsu/config/yaw_trim.json`
- 기립 대기 15분 시 뒷다리 hip 79°C → 기립 후 30초 안에 출발
